# SaaS Website

A modern, responsive SaaS website developed for an AI-powered analytics platform. The project focuses on a clean user interface, responsive layouts, interactive sections, and smooth animations.

## Features

* Modern and responsive SaaS design
* Home, About, Services, Pricing, Dashboard, and Contact pages
* Responsive navigation menu
* Interactive dashboard interface
* Pricing plans section
* AI analytics and insights sections
* Smooth scrolling and animations
* Mobile, tablet, and desktop responsive layout
* Clean and user-friendly interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GSAP
* ScrollTrigger
* Google Fonts
